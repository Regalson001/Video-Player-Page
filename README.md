# HTML Video Player Workshop

A responsive and accessible HTML5 video player built using pure HTML5 markup. This project demonstrates how to structure video content, provide multi-format browser compatibility, set playback controls, and configure custom video poster images.

## Features

- **Multiple Video Sources:** Supports `.mp4`, `.webm`, `.ogg`, and `.mov` formats to maximize cross-browser compatibility.
- **Custom Poster Image:** Displays a preview thumbnail before the video starts playing.
- **Playback Controls:** Built-in video controls enabling play, pause, seek, and volume adjustments.
- **Muted Autoplay Ready:** Configured with `muted` and `loop` attributes for seamless media streaming.
